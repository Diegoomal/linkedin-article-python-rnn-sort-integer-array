# Python - Rede Neural - sort integer array

Exemplo de treino e predição utilizando python 3.10 com a bilbioteca TensorFlow/keras para fazer treino e predição de ordenação de valores em array com valores inteiros.

## Conda Snippets

### Create environment

``` conda env create -n rnn-env -f ./env.yml ```

### Update environment

``` conda env update -n rnn-env -f ./env.yml ```

### Remove environment

``` conda env remove --n rnn-env ```

### Activate environment

``` conda activate rnn-env ```

### Deactivate environment

``` conda deactivate ```

## Run Project

``` python src/train.py ```

``` python src/predict.py ```
